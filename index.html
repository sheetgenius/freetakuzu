Three rules

  1. 01 No runs of threeThree matching digits cannot sit next to each other in any row or column.
  2. 02 Keep it balancedEvery row and column needs the same number of 0s and 1s.
  3. 03 Make each line uniqueNo two completed rows can match, and no two completed columns can match.

How it works

Tap an open square to cycle from blank to 0 to 1. The shaded squares are clues and do not change.

Check marks mistakes. Hint fills one square. Solve shows the answer. Clear removes your entries but keeps the same puzzle.

Each new board starts with a valid solution, then removes squares only while the built-in constraint solver can still finish it. You should not need to guess.
