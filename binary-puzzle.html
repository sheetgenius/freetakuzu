Binary puzzle online

A binary puzzle is a grid logic game built from only two symbols: 0 and 1. The small alphabet makes the rules easy to learn, but the constraints combine into satisfying deductions.

Play binary puzzles free

Binary puzzle rules

  1. Put either a 0 or a 1 in every empty cell.
  2. Never place three identical digits consecutively in any row or column.
  3. Each row and column must contain half 0s and half 1s.
  4. No row can duplicate another row, and no column can duplicate another column.
